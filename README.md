# experimento-cypress
Experimento: Testando uma aplicação web simples com Cypress
1. Objetivos de aprendizagem
Ao final do experimento, os estudantes deverão ser capazes de:
• Criar uma aplicação web simples utilizando HTML, CSS e JavaScript.
• Configurar um projeto no Visual Studio Code.
• Instalar e executar o Cypress.
• Escrever testes end-to-end.
• Interagir com campos, botões e listas.
• Validar mensagens e comportamentos da aplicação.
• Usar seletores estáveis, como data-cy.
• Identificar uma falha intencional em um teste.
2. Aplicação proposta
Você desenvolverá uma pequena aplicação chamada Lista de tarefas.
A aplicação deverá permitir:
1. Digitar uma tarefa.
2. Adicionar a tarefa à lista.
3. Impedir o cadastro de tarefas vazias.
4. Remover uma tarefa.
5. Exibir a quantidade de tarefas cadastradas.
6. Armazenar as tarefas no localStorage
